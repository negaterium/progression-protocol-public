# Support

Use GitHub issues for reproducible bugs, documentation corrections and feature
requests. Include the project version, Node.js version, PostgreSQL major version,
deployment mode and a redacted reproduction. Never attach environment files,
database dumps, credentials, session cookies or player data.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.

This project is a self-hosted application. Support covers the documented
application and deployment workflow; host, reverse-proxy and PostgreSQL provider
operations remain the operator's responsibility.
